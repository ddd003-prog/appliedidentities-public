The oversight pipeline

oversight-pipelinesimulation
observed live divergence measured trust index evidence signed
under specification + authorization heartbeat: connection status signed as recorded

Behavior observed live

Each robot works under a specification and an authorization, the same records every governed agent carries. An independent observer watches actual behavior as the fleet runs, not after the fact.

Divergence measured

The observer measures how far behavior drifts from the specification as it happens, so a problem is visible while it is still small.

A trust index, computed

The stream of measurements resolves into a trust index for the fleet, computed continuously over live oversight events.

Signed evidence

Each oversight event is signed as it is recorded, so the account of what the fleet did is fixed at the moment it happened.

Connection status by heartbeat

A heartbeat reports which robots are connected and when each was last seen, so liveness is never assumed.
