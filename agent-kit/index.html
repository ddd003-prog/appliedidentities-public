Agent Kit

Every agent is a new employee.
None of them were onboarded.

An agent in production sends the email, quotes the price, and answers the customer under your name. A person doing that work gets an identity, a defined role, boundaries, and a review. Agents just get deployed. The Agent Kit is the system that was missing: who each agent is, what it may do, and proof of how it behaved.

Specification

A written role, authority, and limits for every agent. The document that says what the agent is for, what it may decide, and where its authority ends.

Authorization

Signed, scoped credentials that say what it may do. Each credential is narrow, verifiable, and revocable - not a shared key with standing access.

Public record

A live, verifiable ERC-8004 file anyone can read. Identity, chains, and current status resolve on demand at the registry, never cached.

Immediate revocation

Revoke a credential and stop the agent on demand. From that moment every verification path rejects it - proven on the live server on July 17.
